# AuroraReader 中文书源仓库

这是与应用核心分离的声明式规则仓库。默认目录只接收通过“搜索 → 详情 → 章节 → 首图”四阶段实测的公开中文源；规则只描述网址与页面字段，不执行仓库脚本，也不保存账号、Cookie、签名密钥或绕过验证的代码。

## 发布门槛

- 在真实网络和实体设备上完成“关键词搜索 → 详情 → 章节 → 首图”四阶段检查；搜索阶段必须使用
  `searchUrl`，不能用热门列表代替。
- 登录源、成人源和版权状态不清晰的源不进入默认目录。
- 连续三次完全失败时由客户端自动停用，修复并复测通过后才能恢复发布。
- 站点域名、页面结构、访问频率限制或地区策略变化后，规则仍可能失效；维护时优先修规则，不要求用户重装应用。
- 每次修改 `catalog.json` 都要通过项目测试。自动闸门会拒绝解析失败、重复、禁用、非中文、非 HTTPS、
  未使用关键词的搜索规则以及空图片提取规则。

## 维护时怎么验

在项目根目录运行下面的测试；它也是持续集成构建的一部分：

```text
gradlew :app:testDebugUnitTest --tests app.aurora.ppcat.PpcatRuleParserTest --tests app.aurora.ppcat.PpcatSourceHealthCheckerTest
```

静态检查通过后，再从应用的“内容服务 → 检测规则书源”执行全部检测。只有四阶段全部通过，才能把
“候选健康”改为“健康”。

用户发布时可把本目录放到独立 HTTPS/GitHub 仓库，应用通过仓库地址更新 `catalog.json`。第三方网站内容与可用性由其运营方决定，仓库只维护解析规则。

订阅成功后，Android 客户端会在联网且电量正常时每日后台检查一次。仓库下载或解析失败时继续使用
最后一次成功安装的规则；手动“更新规则仓库”入口仍然保留，便于维护者立即验证修复。
