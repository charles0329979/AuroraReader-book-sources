# 规则测试版订阅仓库

固定地址：https://raw.githubusercontent.com/charles0329979/AuroraReader-book-sources/main/rules-test/catalog.json

用于 Aurora 规则测试版 .37 或更新的兼容版本。设置 → 书源中心 → 添加书源 → 粘贴地址 → 检查 → 确认添加。无需安装 APK 书源插件。
手动点击“更新规则仓库”，或等待系统满足联网、电量条件后执行约每日更新任务。不是实时推送。
部分来源仅有目录检索或部分章节可用；收录不代表所有来源全链路健康。
保留 bookSourceKey 和原始身份字段；每次更新先验证受影响规则。新增解析能力仍需升级应用。
旧正式版继续使用根目录 catalog.json，不应切换到本测试频道。
回滚：将本路径恢复为最后验证通过的内容并提交发布，不删除固定地址。
